# PRISM LiveDeck Pro v7.1 — Offline Android Studio Project

## مراحل ساخت فایل APK (فقط ۱ دقیقه):
1. این پوشه را از حالت فشرده (ZIP) خارج کنید.
2. برنامه **Android Studio** را باز کنید و گزینه **Open** را بزنید و پوشه `PRISM_LiveDeck_Android` را انتخاب کنید.
3. صبر کنید Gradle هماهنگ (Sync) شود.
4. از منوی بالا گزینه **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** را بزنید.
5. فایل `app-debug.apk` ساخته می‌شود؛ آن را روی هر دو گوشی نصب کنید.

## نحوه استفاده بدون اینترنت و بدون کد:
1. روی یکی از گوشی‌ها **Hotspot (نقطه اتصال)** را روشن کنید (ترجیحاً باند 5GHz) و گوشی دوم را به وای‌فای آن وصل کنید.
2. برنامه PRISM LiveDeck را روی هر دو گوشی باز کنید:
   - روی گوشی کارگردان: **۲. میز کارگردانی** را بزنید.
   - روی گوشی فیلمبردار: **۱. واحد دوربین فیلمبردار** را بزنید.
3. هر دو گوشی به‌صورت **خودکار و بدون هیچ کدی** همدیگر را روی هات‌اسپات پیدا کرده و وصل می‌شوند.
4. خروجی ضبط MP4 مستقیماً در پوشه `Movies/PRISM_Studio` گوشی کارگردان ذخیره می‌شود.
